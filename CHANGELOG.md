# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] — 2026-06-13

### Added

- R1: AST-only side-effect detection (P0–P4 effects, 38-type taxonomy)
- R2: Classification engine (contractual/ambiguous/incidental)
- R3: CRAP scoring (cyclomatic complexity + line coverage)
- R4: Quadrant analysis and fix strategy recommendations
- R5: JSON and text output formatters
- `gazepy` CLI with `analyze` and `report` subcommands
- Package infrastructure (pyproject.toml, uv.lock, src/ layout)
