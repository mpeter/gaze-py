As a developer running gazepy analyze on code that opens SQLite databases, I want sqlite3.connect() calls to be detected as DatabaseWrite, so that database-creation and connection-establishment operations appear in the analysis output.

Given a function that calls sqlite3.connect(<any_arg>), When gazepy analyze runs, Then DatabaseWrite is emitted with description 'Function opens/creates a SQLite database via sqlite3.connect()'.

Given a function that calls sqlite3.connect(':memory:'), When gazepy analyze runs, Then DatabaseWrite is still emitted (conservative policy — AST cannot distinguish :memory: at analysis time).
