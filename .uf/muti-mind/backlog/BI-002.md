As a developer running gazepy analyze on code that uses functools.cache or functools.lru_cache, I want .cache_clear() calls on module-level cached functions to be detected as GlobalMutation, so that cache-invalidation utilities are correctly scored in GazeCRAP.

Given a function that calls <name>.cache_clear() where <name> is not a parameter, When gazepy analyze runs, Then GlobalMutation is emitted with a description containing 'cache_clear' and the cached function name.

Given .cache_clear() is called on a local variable (not a module-level name), When gazepy analyze runs, Then no GlobalMutation is emitted (local caches are not global state).

Given .cache_clear() is called on multiple module-level cached functions, When gazepy analyze runs, Then one GlobalMutation effect is emitted per call (not deduplicated).
