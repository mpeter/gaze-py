As a developer running gazepy analyze on code that traverses directory trees via Path.glob() or Path.rglob(), I want those calls to be detected as FileSystemMeta, so that filesystem traversal I/O is visible in the analysis output.

Given a function with a Path parameter that calls <param>.glob(pattern), When gazepy analyze runs, Then FileSystemMeta is emitted with description 'Function traverses the filesystem via <param>.glob()'.

Given a function with a Path parameter that calls <param>.rglob(pattern), When gazepy analyze runs, Then FileSystemMeta is emitted with description 'Function traverses the filesystem via <param>.rglob()'.

Given a local Path variable (not a parameter) that calls .glob(), When gazepy analyze runs, Then FileSystemMeta is also emitted (filesystem traversal is observable regardless of path origin).
