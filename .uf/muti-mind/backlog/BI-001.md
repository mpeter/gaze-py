Original scope (multi-provider SDK adapters, streaming, baseline delta) was partially
superseded by `openspec/changes/ai-http-adapters/` (shipped 2026-06-18, PR #39), which
implemented direct HTTP REST adapters for Ollama and Vertex AI — a better approach than
the SDK-based design originally planned here.

Remaining open scope (not covered by ai-http-adapters):

1. **Streaming output** — `--stream` flag using provider SSE/streaming APIs. Ollama
   supports streaming via `stream: true` in `/api/generate`. Vertex supports streaming
   via the streaming `rawPredict` endpoint. Not implemented; deferred.

2. **Baseline delta reporting** — `--baseline <prior.json>` flag to compare the current
   run against a prior JSON snapshot and report regressions/improvements. Not implemented;
   deferred.

If actioning: open a new OpenSpec change for each. The existing `Synthesizer` Protocol
and `OllamaSynthesizer`/`VertexSynthesizer` implementations in `src/gaze_py/report/ai.py`
serve as the foundation — extend them rather than replacing.
