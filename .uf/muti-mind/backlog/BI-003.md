As a developer running gazepy analyze on code that uses contextvars.ContextVar, I want .set() calls on module-level ContextVar objects to be detected as GlobalMutation, so that context-scoped global mutations are visible in the analysis output.

Given a function that calls <name>.set(value) where <name> is a module-level name (not a parameter or local), When gazepy analyze runs, Then GlobalMutation is emitted with a description referencing the ContextVar name.

Given .set() is called on a function parameter (e.g., def fn(cv): cv.set(x)), When gazepy analyze runs, Then no GlobalMutation is emitted (this is a PointerArgMutation pattern).

Given .set() is called on a local variable, When gazepy analyze runs, Then no GlobalMutation is emitted.
