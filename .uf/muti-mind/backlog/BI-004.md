As a developer running gazepy analyze on code that uses deferred imports, I want import and from X import Y statements inside function bodies to be detected as GlobalMutation, so that the mutation of sys.modules (interpreter-global state) is reflected in CRAP scores.

Given a function containing import <module> in its body, When gazepy analyze runs, Then GlobalMutation is emitted with description 'Function performs a lazy import — mutates sys.modules (interpreter-global module cache)'.

Given a function containing from <module> import <name> in its body, When gazepy analyze runs, Then GlobalMutation is emitted with the same description.

Given an import statement at module level (outside any function), When gazepy analyze runs, Then no GlobalMutation is emitted for that import.

Given a function with multiple lazy imports, When gazepy analyze runs, Then one GlobalMutation per distinct import statement is emitted (not collapsed).
